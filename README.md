# javascript-calculator-precourse : 문자열 덧셈 계산기

## 기능 정의서

### 구현 목록

1. **입출력 형식**

   - 입력: `Console.readLineAsync()`로 입력 받기
   - 출력: `Console.print()`로 `"결과 : n"` 형식으로 출력

2. **기본 구분자 등록**

   - 기본 구분자: 쉼표(,)와 콜론(:)
   - 예시 입력: `"1,2:3"`

3. **커스텀 구분자 등록**

   - 커스텀 구분자: `//`와 `\n` 사이 문자를 커스텀 구분자로 사용
   - 예시 입력: `"//;\n1;2;3"`

4. **구분자 기준 숫자 추출**

   - 기본 구분자와 커스텀 구분자를 통합 구분자(정규식 형태로)로 등록하기
   - 정규 표현식, `split()`을 이용해 숫자 추출
   - split 결과의 빈 토큰 제거: `filter(Boolean)` 사용

5. **숫자 덧셈 및 출력**

   - 추출된 숫자를 모두 더한 후 `"결과 : n"` 출력
   - 입력이 빈 문자열("")일 경우 `결과 : 0` 출력

6. **예외 처리**
   - 다음과 같은 경우 `[ERROR]`로 시작하는 메시지를 출력 후 예외 발생
   - 프로그램은 `process.exit()`를 직접 호출하지 않고 종료됨

### 6번 목록의 출력 기준 세부적으로 구분하기

1. 정상 출력 기준

   - 입력이 다음과 같을 경우에 정상 출력을 한다.

     - 경우 1.
       - 쉼표(,) 또는 콜론(:)을 구분자로 사용
       - 예시 입력: `"1,2"`, `"1:2"`
     - 경우 2.
       - 쉼표(,)와 콜론(:)을 동시에 사용
       - 예시 입력: `"1,2:3"`
     - 경우 3.
       - 커스텀 구분자가 1번 선언되어 사용됨
       - 예시 입력: `"//;\n1;2;3"`
     - 경우 4.
       - 빈 문자열 입력
       - 예시 입력: `""`
       - 결과: 0 출력

   - 설명:
     - 커스텀 구분자는 `//`와 `\n` 사이의 문자로 정의한다.
     - 커스텀 구분자는 한 번만 선언 가능하며, 선언된 구분자를 기준으로 숫자를 분리한다.
     - 입력 문자열에 구분자가 없을 경우, 단일 숫자로 본다.

2. 오류 출력 기준

   - 입력이 다음과 같을 경우에 오류 출력을 한다.

     - 경우 1.
       - 커스텀 구분자가 중복 선언됨
       - 예시 입력: `"//|\n//~\n1|2~3"`
       - 예상 처리: `[ERROR] 커스텀 구분자는 한 번만 선언할 수 있습니다.`
     - 경우 2.
       - 숫자가 존재하지 않음
       - 예시 입력: `"//;\n;;;"`, `"abc"`
       - 예상 처리: `[ERROR] 현재 입력에 숫자가 존재하지 않습니다.`
     - 경우 3.
       - 음수 입력
       - 예시 입력: `"//|\n//~\n1|2~-3"`
       - 예상 처리: `[ERROR] 음수는 입력할 수 없습니다.`

   - 설명:

     - `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션을 종료한다.

     - 프로그램 종료 시 `process.exit()`를 직접 호출하지 않는다.
